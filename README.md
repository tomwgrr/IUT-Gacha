## 💾 Save Data

The game uses two JSON files for data persistence :

| File | Description |
|---|---|
| `player_collection.json` | Player's collection data (cards/items obtained, etc.) |
| `game_state.json` | Global game state data (progress, settings, etc.) |

> **Note:** Save data is **not protected or encrypted** in any way — it's stored as plain, editable JSON. Nothing technically stops you from modifying these files, but please play fair and avoid editing your save data to gain an unfair advantage. Enjoy the game as intended!
